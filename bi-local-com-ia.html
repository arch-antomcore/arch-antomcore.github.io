// exemplo de uso específico

Consolidação de Múltiplos Relatórios de Vendas Trimestrais

Controladores de negócios frequentemente recebem diversas planilhas de vendas isoladas de diferentes filiais ou sistemas. Cruzar essas bases para gerar um report executivo consolidado exige muito trabalho manual ou exposição em plataformas de BI na nuvem. Com o AetherCore:

Fluxo do Caso Prático:
1. O usuário vincula a pasta `/workspace/vendas-q1` contendo três arquivos XLSX de filiais.
2. A IA monta as planilhas sob um banco de dados local SQLite em memória.
3. A IA executa queries estruturadas locais para unificar registros e calcular margens agregadas.
4. O runtime exporta um relatório financeiro final consolidado `CONSOLIDADO_Q1.XLSX` e um sumário executivo em PDF, sob autorização pelo ARL (Approval Layer).

// FAQ específico

Dúvidas sobre BI Local com IA

Respostas objetivas sobre diferencial, integração e formatos de saída.

Qual o diferencial do BI local do AetherCore em relação a dashboards em nuvem? +

Os dashboards em nuvem exigem carregar seus dados confidenciais para servidores de terceiros. O AetherCore oferece inteligência local-first: as análises e processamentos de dados são feitos fisicamente na sua máquina.

É possível conectar o AetherCore a bancos de dados SQL locais? +

Sim. O AetherCore possui ferramentas integradas para ler e indexar dados diretamente de bancos locais como SQLite, Postgre ou MySQL corporativos em rede local sob políticas do ARL.

Como os relatórios executivos finais são gerados? +

O Aether Agent escreve relatórios prontos em arquivos locais de sua escolha (como Markdown, planilhas XLSX ou PDFs estruturados via motor local CEF), permitindo a revisão imediata do operador.

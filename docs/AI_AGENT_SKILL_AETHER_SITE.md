# Skill — AetherCore Website & Centelha

Use esta skill ao alterar o site AetherCore/Exvorn.

## Prioridades
1. Preservar estética cyberpunk premium, GSAP, WebGL, matrix canvas, magnetic buttons e microinterações.
2. Manter HTML semântico e multipage: uma intenção principal por URL, um H1 por página, title e description únicos.
3. Nunca prometer segurança absoluta. Usar: prioriza execução local, reduz exposição, uplink explícito, aprovação humana, trilha auditável.
4. Alinhar naturalmente com Centelha: solução, mercado, impacto socioambiental, equipe, consistência, cronograma e orçamento.
5. Otimizar para busca clássica e AI search: conteúdo textual rastreável, JSON-LD coerente, sitemap, robots, llms.txt, links internos.
6. Respeitar acessibilidade: alt text, foco, contraste, prefers-reduced-motion e conteúdo equivalente quando animações forem reduzidas.

## Checklist antes de entregar
- `node --check assets/aether-awwwards.js` sem erros.
- Todos os canonicals apontam para `https://exvorn.tech`.
- Sitemap inclui todas as páginas publicáveis.
- FAQ visível no HTML quando houver FAQPage.
- Nenhuma página satélite é cópia rasa de outra.
- Formulário e CTAs possuem IDs/classes de tracking.
